# Echelon Fox Website

World-class digital marketing company website built with Next.js 16, TypeScript, and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Build for Production

```bash
npm run build
npm start
```

## Deploy

Push to GitHub and deploy instantly via [Vercel](https://vercel.com) (recommended) or any Node.js host.

## Structure

- `app/` — Next.js App Router pages and layout
- `components/` — All page sections (Nav, Hero, Marquee, Services, Work, Stats, About, Testimonials, CTA, Footer)
